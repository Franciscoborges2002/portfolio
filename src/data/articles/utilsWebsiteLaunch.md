## Introduction

Today I finally shipped my newest project: [utils.fborges.dev](https://utils.fborges.dev). It’s my second “vibe coding” mini-project — a small but carefully curated collection of utilities designed to make web development faster. Whether you're troubleshooting, experimenting, or building something new, these tools aim to make the workflow feel lighter.

<span id="features"></span>

## Features

- **Different Types of Tools**  
  From generators to formatters to debugging helpers, the platform offers a growing variety of utilities.

- **Categories and Search bar for Easy Navigation**  
  All tools are organized into clear categories and a search bar is provided in order to quickly find exactly what you need.

- **Useful Resources Page**  
  A dedicated page listing helpful links, references, and external tools to speed up development and support everyday coding tasks.

- **Minimal UI**  
  A simple, distraction-free interface that lets you focus on the tool at hand without unnecessary visual noise.

- **Theme Options**  
  Switch between different themes for a more comfortable and personalized experience.

<span id="roadmap"></span>

## RoadMap

- **More Utilities**  
  Continuously expand the platform with new tools based on personal needs and community feedback.

- **User Feedback Integration**  
  Add ways for users to suggest new tools, report issues, and shape the direction of the project.
